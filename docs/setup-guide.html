Twilio: رقم التليفون

لما العميل يتصل، المكالمة بتوصل لـTwilio، وTwilio بيبعت الصوت لسيرفر موسى. لكل براند هيبقى ليه رقم Twilio خاص بيه.

  1. ادخل twilio.com/try-twilio وسجّل بإيميلك. هيبعتلك كود على الإيميل، وبعدين كود SMS على موبايلك.
  2. هيسألك أسئلة تعريفية. اختار: Which product? ← Voice · Language ← Python · Goal ← Build something new
  3. هتدخل الـConsole. انزل لتحت لحد مربع Account Info، هتلاقي Account SID وAuth Token. التوكن مستخبي، اضغط Show عشان يظهر.
  4. اشحن الحساب: من القائمة فوق Admin ← Billing (أو Upgrade account)، وحط كارت واشحن 20$. الحساب التجريبي بيشغل رسالة "trial account" في أول كل مكالمة، وده هيبوّظ التجربة. عشان كده الشحن مهم.
  5. اشتري رقم: من القائمة الجانبية Phone Numbers ← Manage ← Buy a number. اختار United States وعلّم على Voice، واضغط Buy قدام أي رقم. الرقم الأمريكي أرخص وأسهل. العملاء في مصر والسعودية مش هيتصلوا بيه مباشرة، البراند هيحوّل رقمه المحلي عليه (call forwarding).
  6. اسمح بالتحويل لمصر والسعودية: Voice ← Settings ← Geo permissions، وعلّم على Egypt وSaudi Arabia واحفظ. ده عشان لما موسى يحوّل العميل لخدمة العملاء على رقم مصري أو سعودي، المكالمة تعدي.

تطلع من هنا بـ:

TWILIO_ACCOUNT_SIDبيبدأ بـ AC
TWILIO_AUTH_TOKEN32 حرف
TWILIO_PHONE_NUMBERمثلًا ‎+1 415…
الخطوة 2مجاني · رصيد ترحيبي (حوالي 200$)

Deepgram: ودان موسى

بيسمع العميل ويكتب كلامه لحظة بلحظة، وبيعرف إمتى خلص كلامه. ده اللي بيخلي موسى ميقاطعش.

  1. ادخل console.deepgram.com وسجّل بحساب Google، أسرع حاجة.
  2. من القائمة الجانبية اختار API Keys. ممكن تلاقيها تحت Settings أو Manage.
  3. اضغط Create a New API Key. الاسم mousa، والـRole Member، والمدة Never expire.
  4. انسخ المفتاح فورًا واحفظه مؤقتًا في ملاحظة على جهازك. مش هيظهر تاني بعد ما تقفل النافذة.

تطلع من هنا بـ:

DEEPGRAM_API_KEYحوالي 40 حرف
الخطوة 3مجاني · الباقة F0 (نص مليون حرف صوت في الشهر)

Azure Speech: صوت موسى

فيه أصوات عربية بلهجات حقيقية: مصري (ar-EG-ShakirNeural) وسعودي (ar-SA-HamedNeural). دي أهم خطوة عشان موسى يبان طبيعي.

  1. ادخل azure.microsoft.com/free واعمل حساب مجاني. هيطلب كارت للتأكيد بس، ومش هيسحب منه طول ما إنت على الباقة المجانية.
  2. ادخل portal.azure.com، واكتب في البحث فوق Speech، واختار Speech services. ممكن يظهر تحت اسم Azure AI Speech أو Foundry.
  3. اضغط + Create واملا كده: Resource group ← Create new باسم mousa-rg
    Region ← West Europe
    Name ← mousa-speech
    Pricing tier ← Free F0
  4. اضغط Review + create، وبعدين Create، واستنى دقيقة لحد ما يكتب "deployment complete".
  5. اضغط Go to resource، ومن القائمة الجانبية اختار Keys and Endpoint. انسخ KEY 1 وLocation/Region (هتلاقيها مكتوبة westeurope).
  6. اختياري بس ممتع: ادخل Voice Gallery، اختار Arabic (Egypt) وArabic (Saudi Arabia)، واسمع الأصوات وقولي أنهي صوت عاجبك لموسى.

تطلع من هنا بـ:

AZURE_SPEECH_KEYKEY 1
AZURE_SPEECH_REGIONمثلًا westeurope
الخطوة 4مجاني للتجربة

Gemini: عقل موسى

بيفهم العميل عايز إيه، ويدوّر في بيانات البراند، ويكتب الرد اللي موسى هيقوله.

  1. ادخل aistudio.google.com/apikey بحساب Google.
  2. اضغط Create API key، واختار Create API key in new project.
  3. انسخ المفتاح، هيبدأ بـAIza.
مهم:الباقة المجانية من جوجل ممكن تستخدم البيانات في تحسين منتجاتها. ده عادي في التجربة، لكن قبل ما نشغّل براند حقيقي هنفعّل الدفع (Billing) عشان بيانات العملاء تفضل خاصة.

تطلع من هنا بـ:

GEMINI_API_KEYبيبدأ بـ AIza
الخطوة 5Railway: حوالي 5$ في الشهر · Oracle: مجاني بس أصعب

السيرفر: المكان اللي موسى شغال عليه

موسى لازم يفضل صاحي 24 ساعة ومتوصل بالمكالمة طول وقتها. ترشيحي تبدأ بـRailway لأنه أسهل بكتير، وأنا اللي هرفع الكود عليه. Oracle مجاني للأبد، لكن التسجيل فيه بيترفض أحيانًا، والسيرفر المجاني كتير بيبقى "خلصان" (Out of capacity).

الاختيار المرشح: Railway

  1. ادخل railway.com واضغط Login ← Login with GitHub بنفس حساب GitHub اللي فيه الـrepo بتاع موسى.
  2. من Account ← Plans اختار Hobby (حوالي 5$ في الشهر) وحط الكارت.
  3. من Account ← Tokens اعمل توكن باسم mousa وانسخه. ده اللي هيخليني أرفع الكود بنفسي.
  4. بس كده. المشروع والإعدادات عليّا.

تطلع من هنا بـ:

RAILWAY_TOKENمن Account ← Tokens
لو عايز المجاني: Oracle Cloud
  1. سجّل في oracle.com/cloud/free. اختار Home Region Frankfurt أو Jeddah، ومش هتقدر تغيرها بعد كده.
  2. Compute ← Instances ← Create instance، وفي Shape اختار Ampere ← VM.Standard.A1.Flex بـ 2 OCPU و 12GB. متختارش E3 أو E4 أو E5 Flex، دول بفلوس.
  3. Image ← Ubuntu 24.04. علّم على Assign public IPv4، ونزّل الـSSH key واحفظه كويس.
  4. ابعتلي الـPublic IP بس، والـSSH key يتحط في الخزنة (الخطوة 7) مش في الشات.
الخطوة 6مجاني

Supabase: ذاكرة موسى

هنا هتتخزن بيانات كل براند وسجل المكالمات. هنحتاجه في المرحلة 2، فدلوقتي افتح الحساب وبس.

  1. ادخل supabase.com وسجّل بـGitHub.
  2. اضغط New project. الاسم mousa، والـRegion Frankfurt (eu-central-1)، واعمل Database password قوي واحفظه.
  3. بعد ما يخلص، روح Project Settings ← API Keys وانسخ: Project URL · و الـsecret key (القديم اسمه service_role)

تطلع من هنا بـ:

SUPABASE_URLhttps://xxxx.supabase.co
SUPABASE_SECRET_KEYsecret / service_role
الخطوة 7

حفظ المفاتيح في الخزنة

المفاتيح مش هتتبعت في الشات. هتتحط في إعدادات بيئة Claude Code، وأنا أقراها من هناك من غير ما أشوفها مكتوبة قدامي.

  1. في صفحة الجلسة دي، فوق عند عنوان الجلسة، افتح قائمة الـcloud environment.
  2. اضغط Edit.
  3. في قسم Network secrets (أو Environment variables في النسخ القديمة) ضيف كل مفتاح: الاسم من الجدول تحت بالظبط، والقيمة اللي نسختها.
  4. احفظ، وافتح جلسة جديدة. المفاتيح بتشتغل في الجلسات الجديدة بس.
الاسم (انسخه زي ما هو)من فينإمتى نحتاجه

قائمة المتابعة

علّم على اللي خلصته. المتصفح بتاعك بيفتكر القايمة لو قفلت الصفحة ورجعت.

لما تخلص:ارجع للمحادثة واكتب "خلصت الحسابات"، وابعتلي بيانات البراند التجريبي (اسمه ونشاطه وأسعاره ومواعيده وأكتر الأسئلة اللي بتتسأل). وأنا أبدأ المرحلة 1.

قاموس الكلمات

API Key
مفتاح سري بيخلي برنامج موسى يستخدم الخدمة باسمك. زي كارت دخول.
Console / Dashboard
لوحة التحكم بتاعة الموقع بعد ما تسجل دخول.
STT
تحويل الكلام لنص (Speech to Text). ده دور Deepgram.
TTS
تحويل النص لكلام (Text to Speech). ده دور Azure.
LLM
نموذج الذكاء اللي بيفكر ويكتب الرد. ده دور Gemini.
Call forwarding
تحويل المكالمات من رقم البراند المحلي لرقم Twilio، وبيتعمل من شركة الاتصالات أو السنترال.
Region
مكان السيرفر في العالم. كل ما يكون أقرب للعميل، الرد يبقى أسرع.
Webhook
لينك Twilio بينادي عليه أول ما تيجي مكالمة، عشان يقول لسيرفر موسى "رد".
