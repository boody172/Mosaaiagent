بناء موسى بالخطوات

من أول حساب لحد أول مكالمة حقيقية، بالأدوات: Claude Code وSupabase وVercel وElevenLabs وTwilio. كل خطوة فيها مين بيعملها: إنت ولا Claude Code. وكل جزء كود عليه رسالة جاهزة تنسخها وتبعتها لـClaude Code.

مكان الضغط في الرسم ⏱ التجهيز: 2–3 ساعات · البناء مع Claude Code: كام جلسة
تحديث على الخطة الأولى: بالأدوات اللي اخترتها، ElevenLabs Agents هيعمل شغل 3 خدمات لوحده: يسمع العميل، ويفكر بالـLLM، ويرد بصوت. وكمان بيمنع المقاطعة وبيحوّل لموظف. يعني مش محتاج Deepgram ولا Azure ولا Railway من الدليل الأول. Twilio وSupabase زي ما هم.
عن الصور: دي رسومات توضيحية مبنية على شكل المواقع في 2026، مش لقطات شاشة حقيقية. لو زرار مش في مكانه، دوّر على نفس الكلمة بالإنجليزي.

Twilio: اشتري الرقم واعمل مفتاح

  1. سجّل في Twilio وأكّد الإيميل والموبايل. في أسئلة البداية اختار Voice.
  2. اشحن الحساب: Admin ← Billing ← Upgrade بـ20$. الحساب التجريبي بيشغل رسالة "trial" في أول كل مكالمة.
  3. اشتري رقم: Phone Numbers ← Manage ← Buy a number. اختار United States وعلّم على Voice، واضغط Buy.
  4. فعّل التحويل لمصر والسعودية: Voice ← Settings ← Geo permissions، وعلّم على Egypt وSaudi Arabia.
  5. اعمل مفتاح API مخصوص (أأمن من الـAuth Token): Admin ← Account management ← API keys & tokens ← Create API key. الاسم elevenlabs والنوع Standard. انسخ الـSID والـSecret، الـSecret بيظهر مرة واحدة بس.

تطلع من هنا بـ:

TWILIO_PHONE_NUMBERالرقم اللي اشتريته
TWILIO_API_KEY_SIDبيبدأ بـ SK
TWILIO_API_KEY_SECRETيظهر مرة واحدة

ElevenLabs: اعمل موسى

دي أهم مرحلة. هتعمل موسى لأول براند بإيدك عشان تفهم كل إعداد. بعد كده Claude Code هيخلي الموقع يعمل ده لوحده لكل براند جديد.

  1. سجّل في elevenlabs.io، وروح لقسم Agents (ممكن اسمه ElevenAgents).
  2. اضغط + New agent، واختار Blank template، والاسم Mousa - اسم البراند.
  3. First message: سيبه فاضي. كده موسى هيستنى العميل يتكلم الأول، زي ما إنت عايز. لو حسيت إن السكوت في أول المكالمة غريب، نحط "ألو، السلام عليكم" بعد التجربة.
  4. System prompt: ابعت لـClaude Code الرسالة اللي تحت، وهيكتبلك شخصية موسى. انسخ النتيجة وحطها هنا.
  5. Language: الأساسية Arabic، وضيف في Additional languages English وFrench وUrdu وأي لغة تحتاجها.
  6. Voice: اضغط على الصوت، وروح Voice Library، وفلتر Arabic. اسمع واختار صوت راجل مصري وصوت راجل سعودي، واحفظ الاتنين في My Voices. حط المصري كصوت أساسي دلوقتي.
  7. LLM: اختار موديل سريع، زي Claude أو Gemini Flash. السرعة أهم من الذكاء الخارق هنا.
  8. Knowledge base: ارفع ملفات البراند (منيو، أسعار، سياسات، أسئلة شائعة) أو حط رابط موقعه. فعّل Use RAG.
  9. Tools ← System tools، فعّل: End call · Language detection · Transfer to number (حط رقم خدمة العملاء بالصيغة الدولية، مثلًا ‎+20…، والشرط: "العميل صمم يكلم موظف بعد ما موسى حاول يساعده")
  10. Advanced: زوّد Turn timeout شوية (مثلًا 7 ثواني)، وخلي Interruptions شغالة، عشان لما العميل يتكلم موسى يسكت.
  11. اضغط Test AI agent واتكلم معاه من المتصفح بالمصري وبالسعودي.
رسالة لـClaude Code: شخصية موسى
اكتب System Prompt لـElevenLabs Agent اسمه موسى، وحطه في ملف prompts/mousa-system.md في الـrepo.

المطلوب:
- موسى بيرد على مكالمات عملاء براند اسمه {{brand_name}} (dynamic variable).
- أول جملة من العميل تحدد لهجته. يرد بنفس اللهجة: سعودي (نجدي/حجازي حسب العميل)، مصري، خليجي، شامي، أو أي لغة تانية.
- التعريف بعد ما يعرف اللهجة: "وعليكم السلام ورحمة الله وبركاته، معاك موسى من {{brand_name}}، [كيف أقدر أخدمك / أقدر أساعدك إزاي]؟"
- يعرّف نفسه باسمه بس، ومايقولش من نفسه إنه AI. لكن لو العميل سأل بجد "إنت روبوت؟" يرد بصراحة ولطف ويعرض يحوّله لموظف.
- جاد ومحدد ويرد على المطلوب بس. لو العميل هزر، يهزر بخفة.
- العميل المتعصب: يعتذر الأول، ويسمعه للآخر، وبعدين يحل.
- مايخترعش معلومات. لو حاجة مش في الـknowledge base يقول بثقة إن الفريق المختص هيتواصل معاه خلال {{followup_time}}.
- يستخدم transfer_to_number لو العميل صمم يكلم موظف بعد محاولة حل.
- جمل قصيرة مناسبة للكلام في التليفون، من غير قوايم ولا رموز.
- أرقام وأسعار تتقال بالكلام زي ما الناس بتقولها.
اكتب كمان قايمة الـdynamic variables المستخدمة.
المصري والسعودي إزاي؟ موسى بيكتب الرد باللهجة الصح من الـPrompt. أما نبرة الصوت، فهنخلي الموقع يختار صوت سعودي لو رقم المتصل بيبدأ بـ+966، وصوت مصري لو بيبدأ بـ+20. ده بيتعمل في المرحلة و تحت. ملحوظة: في التحويل (call forwarding) بعض شركات الاتصالات بتبعت رقم البراند بدل رقم العميل، فهنجرب ده عملي.

اربط رقم Twilio بموسى

  1. في ElevenLabs، من القائمة اختار Phone Numbers، واضغط + Import number ← From Twilio.
  2. املا البيانات: Label اسم البراند، والرقم بالصيغة الدولية (‎+1…)، وSID = الـAPI Key SID، وToken = الـAPI Key Secret.
  3. بعد الـImport، اختار من Agent موسى بتاع البراند، واحفظ. ElevenLabs بيظبط Twilio لوحده.
  4. اتصل بالرقم من موبايلك. لو موسى رد، يبقى المكالمات شغالة.
المكالمة الدولية:الاتصال من مصر أو السعودية برقم أمريكي بيتحسب عليك مكالمة دولية. للتجربة استخدم واتساب أو Skype أو أي برنامج اتصال رخيص. وللبراندات بعدين هنشوف أرخص طريقة تحويل.
نقطة تفتيش:لحد هنا عندك موسى بيرد على مكالمات حقيقية لبراند واحد، من غير ولا سطر كود. الجاي هو الـSaaS: براندات كتير ولوحة تحكم وسجل مكالمات.

Supabase: قاعدة البيانات

  1. في supabase.com اضغط New project. الاسم mousa، والـRegion Frankfurt (eu-central-1)، واعمل باسورد قوي واحفظه.
  2. من Project Settings ← API Keys انسخ Project URL والـSecret key.
  3. ابعت الرسالة دي لـClaude Code، وهو يعمل الجداول.
رسالة لـClaude Code: قاعدة البيانات
اعمل Supabase migrations في supabase/migrations لمنصة موسى:
- brands: الاسم، النشاط، طريقة الكلام، رقم خدمة العملاء، مدة المتابعة، مالك البراند (user_id)
- phone_numbers: الرقم، brand_id، elevenlabs_agent_id، elevenlabs_phone_number_id
- brand_knowledge: brand_id، النوع (سؤال شائع/سياسة/منتج)، المحتوى
- calls: brand_id، رقم المتصل، المدة، اللغة/اللهجة، الملخص، النص الكامل، هل اتحولت لموظف، تقييم الرضا
- فعّل Row Level Security بحيث كل براند يشوف بياناته بس.
طبّق الـmigrations على مشروع Supabase المربوط واعمل seed لبراند تجريبي.

تطلع من هنا بـ:

SUPABASE_URLProject URL
SUPABASE_SECRET_KEYSecret key

Claude Code: بناء الموقع والـWebhooks

كده بتشتغل مع Claude Code: تكتب طلبك بالعربي، هو يكتب الكود ويرفعه على GitHub، وVercel ينشره تلقائي.

  1. حط المفاتيح في الخزنة: في claude.ai/code افتح قائمة الـcloud environment جنب عنوان الجلسة، واضغط Edit، وفي Network secrets (أو Environment variables) ضيف كل المفاتيح بأسمائها من الجدول اللي في آخر الصفحة.
  2. افتح جلسة جديدة واختار الـrepo boody172/Mosaaiagent. المفاتيح بتشتغل في الجلسات الجديدة بس.
  3. ابعت الرسالة دي. Claude Code هيبني ويرفع على فرع، ويقولك إيه اللي اتعمل.
  4. اقرا ملخصه، واطلب أي تعديل بالعربي عادي.
رسالة لـClaude Code: الموقع والـWebhooks
ابني تطبيق Next.js (App Router + TypeScript) في الـrepo لمنصة موسى، يتنشر على Vercel ويستخدم Supabase:

1. Webhook بداية المكالمة: POST /api/elevenlabs/init
   - يستقبل called_number وcaller_id من ElevenLabs
   - يجيب البراند من phone_numbers ويرجع dynamic_variables (brand_name, followup_time…)
   - يختار voice_id سعودي لو caller_id بيبدأ بـ+966، ومصري لو بيبدأ بـ+20، والافتراضي مصري
   - يتأكد من السر (ELEVENLABS_WEBHOOK_SECRET)، ويرد في أقل من ثانية

2. Webhook نهاية المكالمة: POST /api/elevenlabs/post-call
   - يتحقق من توقيع ElevenLabs، ويحفظ الملخص والنص والمدة والتحويل في calls

3. لوحة تحكم بالعربي RTL للبراند (Supabase Auth):
   - بيانات البراند والأسئلة الشائعة
   - سجل المكالمات بالملخص
   - إحصائيات بسيطة

4. ملف .env.example بكل المتغيرات، وREADME بالعربي.
اختبر الـwebhooks محليًا بطلبات تجريبية قبل الرفع.

Vercel: انشر الموقع

  1. سجّل في vercel.com بـContinue with GitHub.
  2. Add New… ← Project، واختار Mosaaiagent واضغط Import. الـFramework هيتعرف لوحده (Next.js).
  3. اربط Supabase: من المشروع Settings ← Integrations ← Browse Marketplace، دوّر على Supabase واضغط Add Integration، واختار مشروع mousa. متغيرات Supabase هتتحط لوحدها.
  4. من Settings ← Environment Variables ضيف ELEVENLABS_API_KEY وELEVENLABS_WEBHOOK_SECRET وأصوات موسى (VOICE_ID_EG وVOICE_ID_SA).
  5. اضغط Deploy. هتاخد لينك زي mousa.vercel.app. بعد كده كل ما Claude Code يرفع كود، Vercel بينشر لوحده.
فرق مهم:الخزنة في Claude Code عشان Claude يشتغل وهو بيبني. ومتغيرات Vercel عشان الموقع الحقيقي يشتغل. نفس المفاتيح بتتحط في المكانين.

اربط ElevenLabs بالموقع

آخر توصيلة: موسى يسأل الموقع "أنا شغال مع مين؟" أول المكالمة، ويبعتله الملخص في آخرها.

  1. في ElevenLabs روح Settings بتاعة الـAgents (مش بتاعة الوكيل نفسه). في Conversation initiation client data webhook حط: https://mousa.vercel.app/api/elevenlabs/init
  2. في نفس الصفحة، Post-call webhook، حط: https://mousa.vercel.app/api/elevenlabs/post-call انسخ الـwebhook secret اللي هيظهر، وحطه في Vercel باسم ELEVENLABS_WEBHOOK_SECRET.
  3. افتح موسى، وروح Security، وفعّل Fetch initiation client data from webhook. وفي Overrides فعّل Voice عشان الموقع يقدر يغير الصوت.
  4. من Profile ← API Keys اعمل مفتاح ElevenLabs لـELEVENLABS_API_KEY.
  5. اتصل من رقم مصري ومن رقم سعودي، وبعدين ادخل لوحة التحكم وشوف المكالمات اتسجلت.

براند جديد بضغطة زرار

لما الأساس يشتغل، Claude Code يخلي الموقع يعمل كل اللي عملته إنت بإيدك في المرحلة ج ود، لكل براند جديد تلقائي.

رسالة لـClaude Code: تشغيل براند جديد تلقائي
ضيف للوحة التحكم "إضافة براند جديد" فيها أسئلة الـOnboarding كلها (الهوية، المنتجات والأسعار، المواعيد، التوصيل، الدفع، السياسات، الأسئلة الشائعة، الأزمات، الممنوعات، رقم التحويل، ملفات PDF أو رابط الموقع).
لما البراند يحفظ:
- اعمل نسخة من موسى في ElevenLabs بالـAPI بنفس إعدادات الوكيل الأساسي، وحط اسم البراند ورقم التحويل
- ارفع ملفاته للـKnowledge base بتاعته
- اربط رقم Twilio المتاح ليه
- احفظ الـIDs في phone_numbers
وأي تعديل في بيانات البراند يتحدث في ElevenLabs تلقائي.
رسالة لـClaude Code: الاشتراكات والدفع (بعدين)
ضيف صفحة أسعار وخطط اشتراك شهرية بعدد دقائق (مثلًا 300 / 1000 / 3000 دقيقة)، والدفع بـPaymob لمصر وMoyasar للسعودية. وقّف استقبال المكالمات للبراند لو الدقايق خلصت، وابعتله تنبيه قبلها بـ80%. اعمل لوحة Admin ليا فيها كل البراندات والاستهلاك والتكلفة مقابل الإيراد.
